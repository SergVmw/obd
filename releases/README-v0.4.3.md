# H2 Gauge 0.4.3 — локальный production-релиз

**Дата сборки:** 2026-10-13  
**Цель:** `ESP32-S3-WROOM-1-N16R8` · `esp32s3-n16r8` · PlatformIO `espressif32@6.8.1`  
**Config schema:** 6 (схема NVS не менялась)

0.4.3 подготовлен как новая production-версия. Артефакты 0.4.2 оставлены без изменений; упаковщик обновляет только файлы текущей версии.

## Изменения

- Сохраняемые яркости «День» и «Ночь» в веб-интерфейсе представлены ползунками. Отдельный ползунок текущей яркости немедленно задаёт временное значение 5–100%, не записывает его в конфигурацию и не подменяет сохранённые day/night значения. Оно действует до перезагрузки; отдельная кнопка позволяет раньше вернуть сохранённый режим.
- В сервисном режиме продолжают обновляться debounce LPG-входа и производное состояние топлива. API и верхняя карточка показывают выбранное топливо по состоянию входа отдельно от вычисленного `fuelMode`, который становится `UNKNOWN`, когда RPM устарел. Обновление live-состояния в сервисе не интегрирует расход/расстояние в trip.
- В сервисе работает тот же штатный Mode 01 discovery/poller, а не отдельный диагностический поток. Для PID `0x0B` видны состояние support-mask, успешные отправки, совпавшие ответы, тайм-ауты, возраст и latency последнего ответа. Статус содержит свежесть сырых MAP (`0x0B`) и BARO (`0x33`), используемую базу давления, рассчитанный и отфильтрованный boost. Отсутствующие/устаревшие значения передаются как `null`, не как ноль.
- `fix3b`-specific self-test/diagnostic CAN stream в production не добавлялся. Проводка и битрейт CAN не менялись. Неподвижный MAP/boost на холостом ходу без нагрузки сам по себе не считается доказательством неисправности.
