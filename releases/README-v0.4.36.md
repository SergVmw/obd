# Release 0.4.36 — 2026-10-22

Обновление веб-панели головной системы (`Wi-Fi STA`, строго Read-Only) поверх
проверенного в автомобиле релиза [`v0.4.35`](README-v0.4.35.md). Схема настроек
`ConfigData` (**Schema 13**, `348 B`), `TripState` (`88 B`) и кольцевой архив
`/trips.bin` (`148 B × 2 048`) не менялись — при OTA-обновлении с `0.4.35` все
настройки, калибровки и история поездок сохраняются без изменений.

---

## 1. Настраиваемая частота обновления экрана магнитолы (`1–10 Гц`)

- **Кнопка `#hzToggle` в верхней панели `web/headunit.html`:** циклическое
  переключение **`1 Гц` (`1000 мс`) → `2 Гц` (`500 мс`) → `4 Гц` (`250 мс`, по
  умолчанию) → `8 Гц` (`125 мс`) → `10 Гц` (`100 мс`)** с мгновенным
  перезапуском таймера опроса и сохранением выбора в `localStorage['h2_poll_hz']`
  на самом ГУ.
- **Адаптивная баллистика стрелок:** длительность CSS-перехода `.needle-grp`
  автоматически подстраивается под выбранную частоту (`450 / 340 / 210 / 110 /
  82 мс`) — плавный ход без ступенек на `1–4 Гц` и минимальная задержка отклика
  на `8–10 Гц`.
- **Самотактуемый опрос без очереди сокетов:** вместо фиксированного `setInterval`
  следующий запрос `GET /api/ro/live` планируется после завершения предыдущего с
  компенсацией времени кругового обхода (`Math.max(20, pollIntervalMs - elapsed)`),
  поэтому на `10 Гц` выдерживается шаг `100 мс` и никогда не возникает лавины
  параллельных соединений при кратковременной помехе Wi-Fi.
- **Публикация `StaLiveSnapshot` `10 Гц` на `ESP32-S3` (`src/main.cpp`):** период
  обновления живого снимка уменьшен с `200 мс` (`5 Гц`) до **`100 мс` (`10 Гц`)**
  синхронно с рендером круглого экрана `DashboardUi`.

## 2. Мгновенный вход без `.local` mDNS на магнитоле Android 7 (`h2-open.html`)

### Почему `http://h2.local/` и `http://h2/` не открывались на Android 7:
1. В AOSP системное разрешение имён `.local` по mDNS (RFC 6762) в `netd`
   появилось только в **Android 12 (API 31)** — на **Android 7** системный
   DNS-резолвер браузера не отправляет mDNS-запросы в Wi-Fi.
2. Точка доступа **Xiaomi 14 (HyperOS)** рандомизирует третью октету подсети
   (`192.168.<X>.0/24`) и не пробрасывает клиентские DHCP-имена (`Option 12`) во
   внутренний DNS для соседних Wi-Fi клиентов.

### Как работает автономный ярлык [`h2-open.html`](h2-open.html):
1. **Мгновенная проверка последнего адреса (`~30–60 мс`):** первым запросом
   проверяется `localStorage['h2_last_host']`. Если подсеть и аренда не
   изменились, панель приборов открывается практически мгновенно.
2. **Автоматическое обнаружение новой подсети хотспота (`~100–450 мс`):**
   - извлекает текущую частную подсеть Android-магнитолы через локальный
     ICE-кандидат `RTCPeerConnection` и список ранее встречавшихся подсетей
     `localStorage['h2_subnets']`;
   - при отсутствии WebRTC-кандидата определяет активную подсеть `192.168.<X>.0/24`
     по мгновенному отклику локального шлюза `192.168.<X>.1`;
   - параллельно опрашивает `.2..254` простыми CORS-запросами `GET /api/ro/live`,
     проверяет сигнатуру ответа `H2 Gauge` (`version`, `hostname`, `obdConnected`,
     `cur`), сохраняет найденный IP в `localStorage` и автоматически переводит
     экран через `location.replace('http://<IP>/')`.
3. **Ожидание зажигания / точки доступа + ручной ввод одной подсети:** если
   открыть ярлык до запуска точки доступа или до включения зажигания, поиск
   автоматически повторяется каждые `2,5 с` без касаний экрана. При желании в
   поле можно один раз ввести полный IP или только одно число `X` подсети.
4. **Доставка файла на магнитолу в 1 касание:**
   - готовый файл лежит в релизе: [`releases/h2-open.html`](h2-open.html);
   - либо скачивается прямо на магнитоле кнопкой **`[Ярлык]`** в шапке
     веб-панели (`GET /h2-open.html`, без `gzip`, с заголовком
     `Content-Disposition: attachment` для штатного `DownloadManager` Android 7).
5. **Чистый ES5 (`Chrome 51+` / Android 7.0):** из `web/headunit.html` и
   `web/h2-open.html` полностью исключены конструкции новее ES5 (`const`, `let`,
   `=>`, шаблонные строки, `??`, `?.`, `.padStart`, `AbortController`,
   `async/await`, `NodeList.forEach`), что контролируется автоматическим гейтом
   `tools/check_sta_readonly_integration.py`.
