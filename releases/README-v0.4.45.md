# Release 0.4.45 — 2026-10-28

Страница автопоиска стала легче на 3 950 байт и перестала начинать с нуля там,
где адрес уже известен. Прошивка стала меньше, а не больше.

Дефект найден на машине: головное устройство на Android 11 не нашло прибор в
хотспоте `10.92.230.x`, подключение получилось только вводом адреса руками.
Причина не в браузере и не в переборе: страница искала только в `192.168.*`.

---

## 1. Адрес, который страница уже знает, проверяется первым

**Как было.** `runDiscoveryRound()` собирала список прямых кандидатов: `?host=`,
`192.168.4.1`, хэш адреса, последний сохранённый адрес, `h2.local`. Поле ввода
читалось только по нажатию кнопки. То есть адрес, который человек уже набрал, но
по которому ещё не нажал, в поиске не участвовал вообще.

**Как стало.** Перед перебором проверяются два дополнительных кандидата:

* `location.hostname` — если страница открыта с самого прибора, адрес виден в
  адресной строке, и это факт, а не догадка;
* полный адрес, набранный в поле ввода. Число без точек (`92`) адресом не
  считается: это номер подсети, а не хост.

Оба проверяются одним запросом `/h2probe` и стоят впереди точки доступа и
перебора. Адрес, который ответил, заканчивает круг сразу.

## 2. Страница отдаёт свой адрес вместе с собой

**Как было.** Кнопка «Ярлык» отдавала `h2-open.html` как есть. Файл,
скачанный на головное устройство, не содержал никакого намёка на адрес.

**Как стало.** В странице объявлена точка вставки:

```js
var INJ='',AP_HOST = Q.apHost || INJ || '192.168.4.1';
```

При отдаче по `GET /h2-open.html` сервер подставляет в неё свой адрес в STA —
тот, который он получил по DHCP. Скачанный файл содержит
`var INJ='10.92.230.168'` и находит прибор с первой попытки. Если радио
выключено, подставляется пустая строка, и файл побайтово совпадает с вшитым в
прошивку.

Отдача идёт тремя кусками — «до адреса», адрес, «после адреса» — без копии
страницы в куче: 20 КБ в PSRAM на каждый запрос были бы неоправданны, а
`Content-Length` считается по всем трём.

## 3. Комментарии убраны, страница стала легче

Из `h2-open.html` удалены **55 строк комментариев** (3 950 байт). Все они были
отдельными строками, поэтому правило удаления простое и безопасное: удаляется
строка, у которой первый непробельный символ — `//`. Строки, где `//` стоит
внутри литерала (`'http://' + host`), не затрагивались и проверены глазами.

| | было | стало |
|---|---|---|
| `web/h2-open.html` | 24 313 B | **20 363 B** |
| запас до бюджета 24 КиБ | 263 B | **4 213 B** |
| `app.bin` | 1 458 704 B | **1 455 056 B** |

Запас в бюджете и был причиной, по которой правка не влезала: первый вариант
изменения весил 1 021 байт при свободных 263. Осмысленное содержание
комментариев перенесено в `docs/WEB_INTERFACE_GUIDE.md`, раздел про автопоиск:
логика перебора живёт в документации, а не в байтах, которые прибор передаёт по
Wi-Fi.

## 4. Что НЕ изменилось

* Перебор по-прежнему идёт только по `192.168.*`. Подсеть вида `10.x` страница
  не находит ни в одном круге. Расширение отклонено осознанно: при маршруте по
  умолчанию «своя подсеть без адреса» и «чужая подсеть» дают одинаковый таймаут,
  различать их нечем, а цена — около восьми минут на круг.
* `h2.local` не работает в Chrome на Android — так и остаётся.
* Схема конфига не менялась: `14`. Настройки переживают обновление.
* Топливная модель не менялась.

## 5. Проверка

* 19 host-наборов, все зелёные; в `sta_readonly_tests.cpp` добавлены проверки
  сборки страницы из трёх кусков и арифметики `Content-Length`;
* `check_sta_readonly_integration.py`: gzip головного UI 15 288 B, страница
  20 363 B из бюджета 24 576;
* `check_production_profile.py`, `check_doc_links.py`, `check_ci_coverage.py` —
  без изменений;
* четыре сборки: `esp32s3_n16r8`, `_diagnostic`, `_diaglong`, `_speeddensity`;
  строка `0.4.45-diag.1` подтверждена в собранном образе;
* `check_packaged_artifacts.py`: артефакты сверены с пересборкой.

## 6. Что проверить на машине

1. Скачать ярлык кнопкой «Ярлык» с головного устройства и открыть его
   **не вводя адрес** — должен подключиться сам, если прибор в STA.
2. Убедиться, что в скачанном файле есть `var INJ='<адрес прибора>'`.
3. Повторить запуск после выключения и включения зажигания: адрес запомнен,
   поиск должен закончиться первым же запросом.
4. Проверить, что ручной ввод по-прежнему работает и для полного адреса, и для
   номера подсети.
