# H2 Gauge 0.3.1 — подключения ESP32-S3 DevKitC-1 N16R8

## Целевая плата

Текущая аппаратная цель проекта:

```text
ESP32-S3 DevKitC-1 compatible
ESP32-S3-WROOM-1-N16R8
16 MB QSPI Flash
8 MB OPI PSRAM
два USB-C
```

Маркировку `N16R8` необходимо проверить непосредственно на металлическом экране модуля. Прошивка при старте выводит в serial log обнаруженные размеры Flash и PSRAM и сообщает ошибку, если не найдено примерно 16/8 МБ.

> Перед работой с проводкой выключите зажигание. Не подключайте автомобильные 12 В к GPIO, 3V3 или 5V ESP32-S3.

## Полная карта GPIO

| Функция | ESP32-S3 | Подключение |
|---|---:|---|
| TWAI TX | GPIO16 | SN65HVD230 pin 1 D/TXD |
| TWAI RX | GPIO17 | SN65HVD230 pin 4 R/RXD |
| Кнопка MODE/WAKE | GPIO4 | кнопка между GPIO4 и GND, active LOW |
| LPG sense | GPIO5 | коллектор PC817/EL817, pull-up 10 кОм к 3.3 В |
| TFT backlight PWM | GPIO7 | только на управляющий вход внешнего ключа |
| TFT CS | GPIO10 | GC9A01 CS |
| TFT DC | GPIO11 | GC9A01 DC |
| TFT RST | GPIO12 | GC9A01 RST/RES и 10 кОм к GND |
| TFT MOSI/SDA | GPIO13 | GC9A01 SDA/MOSI |
| TFT SCLK | GPIO14 | GC9A01 SCL/SCLK |

### Намеренно не используемые GPIO

- GPIO19/20 — native USB D−/D+;
- GPIO35/36/37 — заняты Octal PSRAM у N16R8;
- GPIO0/3/45/46 — strapping/boot pins;
- GPIO38 — RGB LED на распространённой DevKitC-1 v1.1;
- GPIO43/44 — UART0, оставлены свободными для диагностики через USB-UART.

## GC9A01 → ESP32-S3

Перед пайкой сверить надписи конкретного восьмивыводного модуля дисплея.

| GC9A01 | ESP32-S3 / цепь |
|---|---|
| GND | GND |
| VCC | 3V3 |
| SCL/SCLK | GPIO14 |
| SDA/MOSI | GPIO13 |
| RES/RST | GPIO12 |
| DC | GPIO11 |
| CS | GPIO10 |
| BLK/BL | 3.3 В через подтверждённый ключ или временно напрямую на стенде |

Возле дисплея установить:

```text
3V3 — 100 нФ — GND
3V3 — 10 мкФ — GND
GPIO12/RST — 10 кОм — GND
```

Резистор 10 кОм удерживает контроллер GC9A01 в reset до настройки GPIO12 и предотвращает белую/цветную вспышку перед логотипом HAVAL.

## Подсветка GC9A01

На текущем стенде BL/BLK можно оставить на постоянных 3.3 В, если конкретный модуль это допускает. В таком случае веб-настройка яркости не действует, а GPIO7 остаётся неподключённым.

Для подтверждённого active-HIGH входа BLK используется high-side каскад:

```text
+3V3 → Q201 AO3401A source pin 2
Q201 drain pin 3 → TFT BLK
Q201 gate pin 1 → R210 100 кОм → +3V3
Q201 gate pin 1 → Q202 MMBT3904 collector pin 3
GPIO7 → R211 4.7 кОм → Q202 base pin 1
Q202 base → R212 100 кОм → GND
Q202 emitter pin 2 → GND
```

GPIO7 HIGH включает подсветку. LEDC duty 0 выключает её, duty 100% включает полностью. Если BLK является катодом светодиода или модуль не содержит ограничения тока, этот каскад не применять — нужен рассчитанный LED-driver.

## CAN-трансивер рядом с ESP32-S3

SN65HVD230 должен находиться в коробке дисплея рядом с ESP32-S3. По длинному межблочному кабелю передаются дифференциальные CAN-H/CAN-L, а не несимметричные TX/RX 3.3 В.

| SN65HVD230 | Соединение |
|---:|---|
| pin 1 D/TXD | GPIO16 |
| pin 2 GND | GND ESP32-S3 |
| pin 3 VCC | 3V3 ESP32-S3 |
| pin 4 R/RXD | GPIO17 |
| pin 5 Vref | NC |
| pin 6 CANL | OBD pin 14 через витую пару |
| pin 7 CANH | OBD pin 6 через витую пару |
| pin 8 Rs | GND для high-speed mode |

Непосредственно возле pin 3/2 установить:

```text
100 нФ керамика
1 мкФ керамика, рекомендуется
```

На CANH/CANL допустима специализированная ESD-защита, например PESD1CAN-U. Дополнительный терминатор 120 Ом не устанавливать. Если он припаян на готовом CAN-модуле, удалить его или разомкнуть перемычку `TERM`.

## OBD-II → коробка питания

Рекомендуется привести пять контактов:

| OBD-II | Сигнал | Назначение |
|---:|---|---|
| 16 | VBAT +12 В | только на защищённый вход питания |
| 4 | chassis ground | возврат питания |
| 5 | signal ground | сигнальная земля/CAN reference |
| 6 | CAN-H | витая пара до трансивера |
| 14 | CAN-L | витая пара до трансивера |

Практически удобно использовать шестижильный кабель, оставив одну жилу резервной. Pins 4 и 5 привести отдельно и объединить в предусмотренной общей точке схемы.

## Коробка питания → коробка дисплея

Минимально нужно пять электрических соединений:

```text
+5V_PROTECTED
GND
CAN-H
CAN-L
LPG_SENSE
```

Рекомендуемый шестижильный межблочный кабель:

| Контакт | Сигнал |
|---:|---|
| 1 | +5V_PROTECTED |
| 2 | POWER_GND |
| 3 | CAN-H |
| 4 | CAN-L |
| 5 | LPG_SENSE |
| 6 | SIGNAL_GND |

Рекомендуемая укладка тремя парами:

```text
+5V / POWER_GND
CAN-H / CAN-L
LPG_SENSE / SIGNAL_GND
```

Отдельный провод 3.3 В между коробками не нужен. SN65HVD230, TFT и pull-up LPG питаются локальными 3.3 В от ESP32-S3 DevKitC-1.

При длине межблочного кабеля более метра для 5V/GND желательно сечение ориентировочно 0.5 мм²; для CAN и LPG обычно достаточно 0.22–0.35 мм². Для постоянной установки использовать фиксирующиеся разъёмы, не Dupont.

## Размещение узлов по коробкам

### Коробка возле OBD

```text
предохранитель
TVS и входная фильтрация
TPS26600 / защита от переполюсовки и перенапряжения
DC/DC 12 → 5 В
диодный мост входа LPG
входная сторона PC817/EL817
```

CAN-H/CAN-L проходят через эту коробку без преобразования.

### Коробка дисплея

```text
ESP32-S3 DevKitC-1 N16R8
SN65HVD230
GC9A01
кнопка GPIO4
pull-up/RC выхода PC817 на GPIO5
ключ подсветки от GPIO7
локальные развязывающие конденсаторы
```

## Защищённое автомобильное питание

Обычный MP1584/LM2596 сам по себе не является защитой от автомобильных импульсов.

Reference-путь:

```text
OBD pin 16
 → F201 1 A
 → D201 SMCJ30CA + C201/C202
 → U201 TPS26600PWP: reverse polarity, UVLO, OVP≈24.0 В, ILIM≈0.74 A
 → C204/L201/C205
 → MP1584, предварительно настроенный на 5.00 В
 → +5V_PROTECTED
 → 5V/VIN ESP32-S3 DevKitC-1
```

`RTN pin 8` TPS26600 нельзя напрямую соединять с `GND pin 9`, иначе отключается встроенная защита от обратной полярности. Support-компоненты UVLO/OVP/MODE/ILIM/dVdT возвращаются в `PWR_RTN`; нагрузка — в `GND_PROTECTED`.

Делитель `487 кОм / 90.9 кОм / 30.1 кОм` задаёт UVLO около 5.98 В и OVP около 24.03 В. `RILIM=16.2 кОм` задаёт около 0.74 А; `CdVdT=22 нФ` ограничивает скорость включения.

Выход 5 В подаётся на контакт `5V` DevKit, не на `3V3`. Не подключать одновременно внешние 5 В и USB, пока не проверена развязка источников конкретной платы.

## Кнопка MODE/WAKE

```text
GPIO4 — кнопка — GND
```

GPIO4 настроен как `INPUT_PULLUP`, кнопка active LOW. Для длинного провода рекомендуется внешняя подтяжка 10 кОм к 3.3 В и подходящая ESD/RC-защита.

GPIO4 является RTC-capable pin и пробуждает ESP32-S3 из low-voltage deep sleep. Второй источник пробуждения — таймер 30 секунд.

## Вход клапана LPG

Два провода от одной катушки BRC идут отдельной витой парой в коробку защиты:

```text
VALVE_A
VALVE_B
```

Они подключаются к полному мосту `D202…D205 1N4007`, затем через два pulse-rated резистора `2.2 кОм / 0.25 Вт` к LED PC817C/EL817C. Полярность катушки благодаря мосту не имеет значения. Нельзя объединять разные клапаны и нельзя соединять сторону катушки с GND ESP32-S3.

Изолированная сторона:

```text
PC817 pin 4 collector → LPG_SENSE → GPIO5
3V3 → 10 кОм → LPG_SENSE
LPG_SENSE → 100 нФ → SIGNAL_GND
PC817 pin 3 emitter → SIGNAL_GND
```

Сигнал active LOW: включённая катушка открывает фототранзистор и тянет GPIO5 вниз. Внешняя подтяжка обязательна для определённого состояния во время reset/deep sleep, даже несмотря на наличие внутренней подтяжки у GPIO5 ESP32-S3.

## USB-C

На совместимой DevKitC-1 обычно есть два USB-C:

- USB-to-UART;
- native USB ESP32-S3.

Сборка 0.3.1 включает `ARDUINO_USB_MODE=1` и `ARDUINO_USB_CDC_ON_BOOT=1`; основной serial log рассчитан на native USB. GPIO19/20 зарезервированы для USB и в проекте не используются.

Для восстановления после неудачной прошивки можно использовать BOOT/RESET и USB-UART. Перед подключением внешних 5 В одновременно с USB проверить схему питания конкретной платы.

## Температурное ограничение

ESP32-S3-WROOM-1-N16R8 с Octal PSRAM имеет паспортный диапазон окружающей среды до +65 °C без PSRAM ECC. Для прототипа плата подходит, но перед постоянной установкой на торпедо нужно измерить температуру корпуса под солнцем и провести тепловые испытания.

## Проверка перед включением

1. Омметром проверить отсутствие короткого замыкания между 5V, 3V3 и GND.
2. Настроить MP1584 на 5.00 В без подключённой ESP32-S3.
3. Первый запуск выполнить от одного USB без автомобильных 12 В.
4. Проверить serial log: Flash около 16 МБ, PSRAM около 8 МБ.
5. Проверить логотип и изображение GC9A01.
6. Проверить кнопку GPIO4 и вход в сервис.
7. Подключить SN65HVD230 и проверить питание 3.3 В возле pin 3.
8. Убедиться в отсутствии 120 Ом на CAN-модуле.
9. Только затем подключать CAN-H/CAN-L к стоящему автомобилю.
10. LPG-вход сначала проверить лабораторными 12–14 В, затем на автомобиле.
