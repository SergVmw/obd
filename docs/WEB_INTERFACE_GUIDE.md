# H2 Gauge 0.3.1 — полная инструкция по веб-интерфейсу

Дата актуализации: 2026-09-16  
Версия прошивки: `0.3.1`  
Версия конфигурации: schema `5`

## 1. Вход в сервисный режим

Веб-интерфейс работает только в специальном сервисном режиме.

### Вариант 1 — при включении питания

1. Нажмите и удерживайте кнопку на GPIO4.
2. Включите питание или нажмите `EN` на ESP32.
3. Продолжайте удерживать кнопку не менее 3 секунд.
4. На дисплее появится экран `СЕРВИС` с названием Wi‑Fi-сети и IP-адресом.

### Вариант 2 — во время работы

1. Остановите автомобиль.
2. Удерживайте кнопку примерно 5 секунд.
3. Если сырая скорость PID 0D не превышает 3 км/ч, прибор войдёт в сервисный режим.

По умолчанию создаётся сеть примерно такого вида:

```text
H2-Gauge-4F2A
```

Последние четыре символа уникальны для ESP32.

Заводской пароль:

```text
h2gauge18
```

Адрес веб-интерфейса:

```text
http://192.168.4.1
```

После подключения желательно отключить на телефоне VPN и, если мешает открытию страницы, мобильный интернет.

## 2. Общий принцип сохранения

В нижней части страницы находится кнопка **«Сохранить настройки»**. Она сохраняет все поля разделов:

- «Экран»;
- «Наддув»;
- «Расход / ГБО»;
- «Управление»;
- «OBD»;
- «Система».

Большинство настроек полностью применяется после выхода из сервиса и перезапуска прибора.

### Действия, которые выполняются сразу

Общая кнопка сохранения для них не требуется:

- запуск бензинового калибровочного интервала;
- применение полной заправки;
- сброс обычной поездки;
- очистка CAN Monitor;
- перезагрузка;
- полный заводской сброс;
- установка прошивки.

Если изменить обычные поля и перезагрузить прибор, не нажав **«Сохранить настройки»**, изменения будут потеряны.

Начиная с 0.3.1 сохранение настроек транзакционное: сервер сначала проверяет весь новый набор, затем сохраняет его в NVS и только после этого оставляет активным. При ошибке проверки возвращается HTTP 422, а при ошибке NVS — HTTP 500; прежняя конфигурация остаётся активной. Числовые поля должны быть конечными, а пороги наддува обязаны удовлетворять условию `минимум < 0 < жёлтая зона < красная зона ≤ максимум`.

## 3. Верхняя строка состояния

Вверху страницы отображаются четыре карточки.

### CAN / OBD

- **Подключено** — недавно получен ответ OBD.
- **Нет связи** — свежих ответов нет.

В сервисном режиме активные OBD-запросы приостанавливаются, поэтому через некоторое время надпись **«Нет связи»** может быть нормальной. Пассивный приём CAN Monitor при этом продолжает работать.

### ECU

Показывает последний обнаруженный идентификатор блока двигателя, например `0x7E8`.

### Наддув

Последнее актуальное значение относительного давления, например `+0.72 bar`. Если свежего MAP нет, отображается `—`.

### Топливо

Возможные состояния:

- `95` — бензин;
- `LPG` — газ;
- `OFF` — двигатель выключен;
- `UNKNOWN` — нет актуальных данных;
- `DFCO` — обнаружено торможение двигателем с отключением подачи топлива;
- `Калибровка ГБО!` — STFT + LTFT на газе слишком долго находятся за пределами ±10%.

## 4. Раздел «Экран»

### Интерактивный предпросмотр

Круглый предпросмотр позволяет проверить:

- цвета;
- тип шкалы;
- диапазон наддува;
- жёлтую и красную зоны;
- язык;
- центральное значение;
- индикатор `95` или `LPG`.

#### Тестовый наддув

Ползунок меняет только предпросмотр. Он не записывается в ESP32 и не влияет на реальные показания.

#### Топливо в предпросмотре

Позволяет выбрать `LPG` или `95`. Если глобальный переключатель ГБО выключен, вариант LPG блокируется и предпросмотр переключается на `95`.

### Дневная яркость

- Диапазон: `10…100%`.
- Заводское значение: `82%`.
- Управляет PWM на GPIO7.

На текущем стенде, где BL/BLK подключён напрямую к 3,3 В, настройка яркости ничего не изменит. Она начнёт работать только после установки аппаратного ключа подсветки или подтверждения, что BLK конкретного дисплея является штатным logic-входом.

### Ночная яркость

- Диапазон: `5…80%`.
- Заводское значение: `26%`.

Значение сохраняется, но в версии 0.3.1 автоматическое переключение день/ночь ещё не реализовано. В нормальном режиме сейчас используется дневная яркость.

### Ориентация

Варианты: `0°`, `90°`, `180°`, `270°`. Настройка поворачивает всё изображение GC9A01.

### Язык надписей прибора

Варианты: русский и English. Меняется язык надписей на GC9A01. Сам веб-интерфейс пока остаётся русским.

### Стартовый экран

Варианты:

1. Главный;
2. Расход / поездка;
3. Температуры;
4. Диагностика OBD.

Если выбранный экран отключён соответствующей галочкой, прибор запустится с главного экрана.

### Значение в центре главного экрана

#### Наддув

Показывается относительное давление в `bar`.

#### Скорость

Показывается скорость с учётом настройки **«Коррекция скорости»** из раздела OBD.

#### Текущий расход

Показывается:

- л/ч при низкой скорости;
- л/100 км после превышения заданного порога.

#### Средний расход текущего топлива

Среднее автоматически следует активному виду топлива:

- бензиновый накопитель в режиме `95`;
- газовый накопитель в режиме `LPG`.

### Автовозврат на главный экран

- Диапазон: `0…120 секунд`.
- Заводское значение: `5 секунд`.

После заданного времени вспомогательный экран автоматически сменяется главным. Значение `0` полностью отключает автовозврат.

### Экран расхода

Добавляет или убирает страницу расхода из цикла коротких нажатий кнопки.

### Экран температур

Добавляет или убирает страницу температур.

### Служебный экран OBD

Добавляет диагностическую страницу с информацией о связи и PID. Экран не отправляет произвольные CAN-команды и не стирает ошибки автомобиля.

### Пиковый наддув

Включает маркер максимального зафиксированного наддува.

Для сброса пика:

1. Откройте главный экран.
2. Выполните обычное длинное нажатие.
3. Автомобиль должен стоять, если включена блокировка действий в движении.

### Цвета интерфейса

| Опция | Назначение | Заводское значение |
|---|---|---|
| Цифры и значения | Основные числа и центральный показатель | `#F2FAF7` |
| Вакуум | Отрицательная часть шкалы | `#5DC9E8` |
| Наддув | Нормальное положительное давление | `#5EF0A8` |
| Предупреждение | Жёлтая зона | `#FFBD59` |
| Опасная зона | Красная зона | `#FF5F68` |

ESP32 хранит цвета в формате RGB565, поэтому после сохранения возможна небольшая разница относительно цвета в браузере.

## 5. Раздел «Наддув»

Формула показания:

```text
boost = (MAP − BARO) / 100 + коррекция
```

MAP и BARO измеряются в кПа, результат получается в bar.

### Источник BARO

#### Авто: PID 33 → MAP при запуске → фиксированное

Рекомендуемый начальный вариант. Приоритет:

1. свежий OBD PID 33;
2. MAP при заглушенном двигателе;
3. фиксированное BARO.

#### Только PID 33

Используется PID 33, если он поддерживается автомобилем. Если свежего PID 33 нет, прошивка временно использует фиксированное BARO.

#### MAP при заглушенном двигателе

Когда RPM ниже 50 и MAP находится в диапазоне `70…110 кПа`, значение MAP принимается за атмосферное давление. Если оно ещё не захвачено, используется фиксированное BARO.

#### Фиксированное

Всегда используется значение из поля **«Фиксированное BARO»**.

#### BMP280

Зарезервированный вариант. Поддержка BMP280 в версии 0.3.1 ещё не реализована, поэтому фактически используется фиксированное BARO.

### Вид шкалы турбо

- **Сегментная — рисочками**: шкала строится отдельными радиальными сегментами.
- **Сплошная полоса**: настоящая непрерывная дуга толщиной 8 пикселей.

### Фиксированное BARO

- Диапазон: `70…110 кПа`.
- Заводское значение: `99,4 кПа`.

Используется как основной источник в режиме «Фиксированное» и как резерв для других режимов. Атмосферное давление зависит от погоды и высоты, поэтому постоянные `100 кПа` не всегда дают точный ноль наддува.

### Коррекция наддува

- Диапазон: `−0,50…+0,50 bar`.
- Заводское значение: `0,00 bar`.

Примеры:

- `+0,05` увеличивает показание на 0,05 bar;
- `−0,05` уменьшает показание на 0,05 bar.

Сначала нужно правильно настроить BARO. Коррекцию следует использовать только для небольшой остаточной систематической ошибки.

### Минимум и максимум шкалы

- Минимум: `−1,2…0 bar`, default `−1,0 bar`.
- Максимум: `+0,5…+2,5 bar`, default `+1,5 bar`.

Эти параметры изменяют только визуальный диапазон. Они не ограничивают двигатель и не управляют ECU.

### Жёлтая и красная зоны

- Жёлтая: `0,2…2,0 bar`, default `0,90 bar`.
- Красная: `0,3…2,5 bar`, default `1,15 bar`.

Пороги являются только цветовой индикацией. Безопасные значения необходимо определять по характеристикам двигателя и его фактической настройке.

Рекомендуемое соотношение:

```text
минимум < 0 < жёлтая зона < красная зона ≤ максимум
```

### Сглаживание

- Диапазон: `0…2000 мс`.
- Заводское значение: `250 мс`.

`0` отключает фильтрацию. Значения `100…300 мс` обычно дают быстрый и достаточно плавный прибор. Большие значения делают реакцию более плавной, но более медленной.

### «Принять текущий MAP за BARO»

Пытается принять текущий MAP в диапазоне `70…110 кПа` как атмосферное давление. Использовать только при заглушенном двигателе и включённом зажигании.

В версии 0.3.1 это оперативное значение, а не отдельная постоянная калибровка NVS. Для гарантированного постоянного результата запишите полученное значение в поле «Фиксированное BARO», выберите «Фиксированное» и сохраните настройки.

## 6. Раздел «Расход / ГБО»

### Глобальный переключатель «Использовать ГБО»

Это главный выключатель всех функций LPG.

Когда он включён, работают:

- GPIO5;
- определение `95/LPG`;
- расчёт расхода LPG;
- отдельная статистика газа;
- газовые настройки;
- PID 06/07 для контроля STFT/LTFT;
- предупреждение калибровки ГБО.

Когда он выключен:

- GPIO5 не опрашивается;
- газовые настройки скрываются;
- PID 06/07 для LPG не запрашиваются;
- LPG-расход и газовая статистика не отображаются;
- режим работающего двигателя считается бензиновым;
- все бензиновые функции сохраняются.

Заводское значение — **выключено**. Включать только после установки защищённого входа через PC817/EL817 и внешней подтяжки GPIO5.

### Источник расхода бензина

#### Авто: PID 5E → MAF

Рекомендуемый вариант. Сначала используется PID 5E Engine Fuel Rate, а при его отсутствии — расчёт по MAF.

#### Только PID 5E

Расход показывается только при наличии свежего PID 5E. Если Haval его не поддерживает, расход будет отсутствовать.

#### Только MAF

Расход рассчитывается из массового потока воздуха, AFR, плотности бензина и commanded equivalence ratio, если она доступна.

В текущей версии для бензина используются внутренние значения:

```text
AFR: 14,7
Плотность: 745 г/л
```

Точность доводится коэффициентом бензина.

#### Haval CAN

Пока не реализовано. При выборе нормальный расчёт расхода может отсутствовать.

#### MAP/IAT/RPM

Speed-density пока не реализован. Не выбирать для обычной эксплуатации.

### Коэффициент бензина

- Диапазон: `0,500…1,500`.
- Заводское значение: `1,000`.

Коэффициент применяется к текущему расходу, литрам поездки, среднему расходу и расчётному количеству топлива калибровочного интервала.

Пример:

```text
расчёт: 8,0 л
коэффициент: 1,100
итог: 8,8 л
```

Для точной настройки лучше использовать автоматическую full-tank калибровку.

### Переход на л/100 км

- Диапазон: `1…30 км/ч`.
- Заводское значение: `5 км/ч`.

Ниже порога расход показывается в литрах в час, выше — в литрах на 100 км. Для стабильного отображения рекомендуется оставить `5 км/ч`.

### Сохранять поездку

Если включено, обычная поездка сохраняется в NVS примерно раз в минуту. Перед low-voltage deep sleep выполняется принудительное сохранение независимо от этой галочки.

### DFCO

При включении прошивка считает расход равным нулю, если:

```text
дроссель ≤ 1%
RPM > 1000
```

Это предназначено для торможения двигателем, когда MAF продолжает показывать воздух, но форсунки отключены. Функция является эвристикой и должна быть проверена по реальным данным Haval.

## 7. Точная калибровка бензина по полному баку

Калибровочный интервал полностью отделён от обычной поездки. Сброс поездки его не обнуляет.

### Первая полная заправка

1. Заправьте бак до автоматической отсечки.
2. Откройте сервисный интерфейс.
3. Перейдите в «Расход / ГБО».
4. Нажмите **«Начать новый интервал»**.
5. Подтвердите, что бак действительно полный.
6. Выйдите из сервиса и эксплуатируйте автомобиль.

### Следующая полная заправка

1. Снова заправьте бак до полного.
2. Желательно использовать ту же АЗС, колонку и схожее положение автомобиля.
3. Возьмите количество фактически залитых литров из чека.
4. Введите его в поле **«Фактически заправлено до полного»**.
5. Нажмите **«Заправлено до полного — рассчитать K»**.
6. Проверьте число и подтвердите операцию.

Формула:

```text
новый K = фактически заправлено / сырой расчёт прибора
```

Ограничения:

- итоговый коэффициент: `0,5…1,5`;
- фактическая заправка: `1…150 л`;
- должно быть накоплено не менее `0,1` сырого расчётного литра.

### После применения

- новый коэффициент бензина сохраняется немедленно;
- обычная поездка не сбрасывается;
- последний результат остаётся в истории;
- следующий full-tank интервал автоматически начинается с текущей полной заправки.

Повторно нажимать **«Начать новый интервал»** после успешного применения не требуется.

### Значения состояния

- **Состояние** — идёт ли интервал;
- **Рассчитано** — бензин с текущим коэффициентом;
- **Путь на бензине** — расстояние, накопленное в интервале;
- **Текущий K** — действующий коэффициент;
- **Последний результат** — прежние/фактические литры и изменение коэффициента.

### Ограничение при ГБО

Когда сигнал клапана показывает LPG, интервал не накапливает бензин. Если BRC выполняет бензиновый довпрыск одновременно с газом, простой вход клапана его не обнаружит. Поэтому full-tank калибровка будет наиболее точной при поездках преимущественно на бензине или после будущего подключения чтения данных BRC.

## 8. Настройки LPG

Поля видимы только при включённой галочке **«Использовать ГБО»**.

### Коэффициент LPG

- Диапазон: `0,500…2,000`.
- Заводское значение: `1,000`.

Применяется к текущему расходу LPG, литрам и среднему расходу газа.

### AFR LPG

- Диапазон: `10,0…20,0`.
- Заводское значение: `15,5`.

Используется при пересчёте MAF в расход LPG.

### Плотность LPG

- Диапазон: `400…700 г/л`.
- Заводское значение: `540 г/л`.

Фактическая плотность зависит от соотношения пропан/бутан и температуры. Окончательную точность лучше получать коэффициентом LPG по нескольким заправкам.

### Контроль STFT + LTFT на LPG

Если включён:

- запрашиваются PID 06 и PID 07;
- вычисляется `STFT + LTFT`;
- при выходе суммы за ±10% дольше 5 секунд появляется предупреждение.

Предупреждение не является командой немедленно менять карту BRC. Сначала необходимо исключить подсос воздуха, неисправности датчиков и проблемы бензиновой системы.

### Активный уровень LOW

Для выбранной схемы PC817/EL817 обычно должен быть включён. При активной оптопаре GPIO5 притягивается к земле, то есть LPG соответствует уровню LOW.

### Фильтрация

- Диапазон: `100…3000 мс`.
- Заводское значение: `800 мс`.

Сигнал должен непрерывно сохранять новое состояние указанное время, прежде чем режим топлива изменится.

### Задержка выключения

- Диапазон: `0…5000 мс`.
- Заводское значение: `1000 мс`.

Добавляется к основной фильтрации при выключении LPG. При заводских значениях переход обратно на бензин подтверждается примерно через `800 + 1000 = 1800 мс`.

### Электрическая безопасность

GPIO5:

- не имеет внутренней подтяжки;
- требует внешнюю подтяжку 10 кОм к 3,3 В;
- должен подключаться через защищённый вход PC817/EL817;
- не допускает прямой подачи 12 В.

### Ручная проверка коэффициента LPG

Поля:

- **Прибор рассчитал, л**;
- **Фактически заправлено, л**.

Формула:

```text
новый K = текущий K × фактические литры / рассчитанные литры
```

После нажатия **«Рассчитать коэффициент LPG»** новое значение только подставляется в поле. Чтобы оно сохранилось, обязательно нажмите **«Сохранить настройки»**.

Рекомендуется выполнять калибровку LPG после пробега не менее 150–300 км и по возможности усреднять несколько заправок.

### Сбросить поездку

Сбрасывает литры бензина и LPG обычной поездки, расстояние, время на каждом топливе и средние значения. Не сбрасывает отдельный бензиновый full-tank интервал.

## 9. Раздел «Управление»

### Длинное нажатие

- Диапазон: `800…4000 мс`.
- Заводское значение: `1800 мс`.

Обычное длинное нажатие выполняется после отпускания кнопки.

Действия:

- на главном экране — сброс пикового наддува;
- на экране расхода — сброс обычной поездки;
- на остальных страницах в текущей версии отдельного действия нет.

### Вход в сервис

- Диапазон: `3000…10000 мс`.
- Заводское значение: `5000 мс`.

Если кнопка удерживается до этого порога, запускается вход в сервис. Рекомендуется, чтобы время входа в сервис было заметно больше времени обычного длинного нажатия.

Настройка не изменяет загрузочный жест: при включении питания вход в сервис по-прежнему требует удержания около 3 секунд.

### Тайм-аут сервиса

- Диапазон: `3…60 минут`.
- Заводское значение: `15 минут`.

Если сервисная страница закрыта и запросы перестали поступать, прибор перезапустится после тайм-аута. Пока страница открыта, она регулярно запрашивает статус, поэтому сервис считается активным.

### Блокировать длинные действия в движении

Рекомендуется держать включённым. При сырой скорости PID 0D выше 3 км/ч блокируются обычные длинные действия.

Вход в сервис при движении блокируется независимо от этой галочки. Коррекция спидометра на safety-проверки не влияет.

## 10. Раздел «OBD / CAN»

### Тайм-аут OBD

- Диапазон: `50…1000 мс`.
- Заводское значение: `120 мс`.

Если ECU отвечает медленно и увеличивается число тайм-аутов, значение можно повысить, например до `150–200 мс`. Слишком большой тайм-аут замедляет обновление всех параметров, поскольку прошивка ждёт завершения текущего запроса.

### Максимум запросов в секунду

- Диапазон: `5…40`.
- Заводское значение: `30`.

Меньшее значение снижает нагрузку на шину, но замедляет данные. Большее ускоряет обновление, но повышает нагрузку и вероятность тайм-аутов. На стоящем автомобиле быстрые PID автоматически опрашиваются реже.

### Коррекция скорости

- Диапазон: `−20…+20 км/ч`.
- Шаг: `0,5 км/ч`.
- Заводское значение: `0`.

Формула:

```text
показанная скорость = max(0, сырая скорость PID 0D + коррекция)
```

Примеры:

- PID 0D показывает 80, коррекция `−5` → прибор показывает 75 км/ч;
- PID 0D показывает 80, коррекция `+3` → прибор показывает 83 км/ч.

Коррекция используется для отображения скорости, накопления расстояния, расчёта л/100 км и среднего расхода. Для блокировки сервисных действий и определения движения всегда используется сырая скорость PID 0D.

Настраивать лучше по GPS на ровной дороге при нескольких стабильных скоростях. Если ошибка меняется пропорционально скорости, одной постоянной поправки может быть недостаточно.

### CAN Monitor

Монитор хранит агрегированный снимок до 32 комбинаций:

- CAN ID;
- направление RX/TX;
- extended-флаг;
- RTR-флаг.

Для каждой строки показываются направление, ID, DLC, последний payload, количество кадров и возраст последнего кадра.

#### Обновить снимок

Однократно загружает текущее состояние.

#### Авто: выкл./1 с

Включает автоматическое обновление один раз в секунду.

#### Очистить

Удаляет агрегированную статистику из оперативной памяти. Команда ничего не отправляет в автомобильную CAN-шину.

В сервисном режиме активный OBD polling остановлен, но входящие CAN-кадры продолжают приниматься.

## 11. Раздел «Система»

### Имя устройства

- Максимум: 23 символа.
- Заводское значение: `H2 Gauge`.

В версии 0.3.1 это сохраняемое имя для идентификации устройства; на фактическое имя Wi‑Fi влияет отдельное поле ниже.

### Имя точки доступа

- Максимум формы: 31 символ.
- Заводское значение: `H2-Gauge`.

К имени автоматически добавляется уникальный суффикс, например `-4F2A`. Чтобы итоговое имя гарантированно помещалось в стандартный предел SSID, рекомендуется использовать основу не длиннее 26 символов. Изменение применяется после перезапуска.

### Пароль точки доступа

- Диапазон: `8…31 символ`.
- Заводской пароль: `h2gauge18`.

Пароль необходимо сменить после первой установки. Новый пароль применяется после перезапуска.

## 12. Обновление прошивки OTA

Использовать только app-образ с расширением `.bin`, например:

```text
h2-gauge-v0.3.1-esp32s3-n16r8.bin
```

Не загружать:

- `bootloader.bin`;
- `partitions.bin`;
- `merged.bin`;
- образ файловой системы.

### Порядок обновления

1. Полностью остановите автомобиль.
2. Обеспечьте стабильное питание.
3. Откройте раздел «Система».
4. Нажмите **«Выбрать .bin»**.
5. Выберите app-образ.
6. Проверьте имя и размер файла.
7. Нажмите **«Установить»**.
8. Подтвердите операцию.
9. Не выключайте питание и не закрывайте страницу.
10. Дождитесь 100% и автоматической перезагрузки.

Прошивка записывается в резервный OTA-раздел. Установка блокируется при известной сырой скорости выше 3 км/ч и при свежем напряжении ECU ниже 11,3 В, но вручную обеспечить стоянку и стабильное питание всё равно обязательно.

Веб-интерфейс 0.3.1 отправляет обязательный заголовок подтверждения `X-H2G-Action: ota`. Сервер не допускает параллельный OTA и вводит паузу 30 секунд между попытками. При любой ошибке записи или проверки OTA вызывается abort/cleanup, поэтому незавершённая сессия не остаётся активной.

## 13. Системные кнопки

### Загрузить заводские значения

Только подставляет заводские значения в форму. Для фактического применения необходимо нажать **«Сохранить настройки»**.

Заводские значения включают:

- LPG выключено;
- коррекция скорости 0;
- бензиновый и LPG коэффициенты 1,000;
- BARO Auto;
- сегментная шкала;
- русский язык;
- автовозврат 5 секунд.

### Перезагрузить

Немедленно перезапускает устройство. Несохранённые изменения формы будут потеряны.

### Полный заводской сброс

Удаляет:

- все настройки;
- обычную поездку;
- отдельное состояние бензиновой калибровки;
- сохранённые коэффициенты и параметры Wi‑Fi.

После сброса устройство перезапускается. Веб-интерфейс 0.3.1 отправляет обязательный заголовок подтверждения `X-H2G-Action: factory-reset`; сервер отклоняет запрос без него и ограничивает повторный запуск интервалом 10 секунд.
